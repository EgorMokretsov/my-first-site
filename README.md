# Мой первый сайт

Учебный HTML-проект для изучения Git, веток и публикации через GitHub Pages.

## Структура проекта

- `index.html` - главная страница;
- `styles.css` - таблица стилей;
- `README.md` - документация проекта.

## Запуск

Откройте файл `index.html` в браузере.
